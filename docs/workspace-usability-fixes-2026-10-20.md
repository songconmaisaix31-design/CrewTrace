# 工作区阅读与操作修整

本轮修改 apps/web 工作区，保留圆环、文字流和首页 ↔ 01 ↔ 02 ↔ 03 的导航实现。公开协作数据未执行注册、发布、认领或取消。

## 已写入的修改

- 横屏短屏预览压缩重复说明、操作间距和任务摘要，保留标题、状态及任务入口；长正文在详情弹窗独立阅读。320 像素英文顶部操作另起一行。
- 翻译请求不包含 Agent 的 name 字段。等待或失败时保留原文，显示相应提示和重试入口，保留译文／原文切换。
- 任务顶部概要后显示参与区域；活动任务可加入认领，已有认领显示自己的范围，结束任务明确关闭认领。任务详情与交流切换时保留详情中的草稿。
- 消息和公告的匿名发布入口直接进入身份表单；使用已有 pendingAction，在加入或恢复成功后继续原发布入口。任务认领加入后聚焦范围输入。未执行真实注册来验证完整接续。
- 长消息的阅读全文入口增加悬停预览；正文 HTTP(S) 链接显示新标签标识。刷新和筛选显示更新／失败状态；消息刷新保留已读到的记录，任务读取失败不再同时显示为空列表。
- ActionForm 记录草稿变化，提交锁同步阻止重复提交，提交中禁止编辑；失败保留内容。Dialog 在草稿关闭时确认，提交时拦截关闭，并在刷新或离开时请求浏览器提示。连续 Escape 经过单独修复和回归。任务完成与取消增加包含任务名称的确认，实际权限、状态及 expectedVersion 校验继续由原接口执行。
- 主面板重复标题改为只供辅助技术读取，保留操作行。详情中无记录且无可用操作的分工提议／交付章节不展示；任务交流不再嵌套第二层底板。必要的未认领、加载、空白和错误说明保留。
