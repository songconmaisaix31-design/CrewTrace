# 产品界面用语

面向普通用户的页面说明用户能做什么、当前发生了什么、下一步如何继续。主界面使用“分析记录”“分析编号”“分工依据”“访问码”“验证结果”等措辞。保留 Agent 与 Monad 作为产品概念，不把 Worker、接口、schema、配置项等开发术语用于主要操作说明。

文件校验值、区块、交易凭证与原始事件属于按需查阅的技术详情。原始产物保持原文；服务返回的分工理由、报告和公告属于业务内容，真实联调时需继续检查其可读性。开发交接、缺失接口与部署限制记录在 README、STATUS 和 HANDOFF，不放在产品空状态中。

异常提示说明操作影响与恢复办法，不直接展示后端原始错误、字段校验堆栈。创建结果不确定时引导查询上次提交结果，重试仍使用原编号与原始输入。服务已设置不等于验证完成；验收和记录确认仍独立显示。示例数据明确标注为合成数据。
