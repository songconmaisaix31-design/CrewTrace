# CrewTrace Trust Core 版本演进记录

本文件记录可验证信任层从 V0.1 到 V0.3 的实验版本演进，用于区分已经实现的能力与仍未解决的信任边界。各版本的详细证据保留在对应报告中，本文件只做索引与差异说明。

## V0.1 — 单任务凭证与信誉准入

SDK：`@crewtrace/trust-sdk 0.1.0-preview.1`

V0.1 建立 `ct-attestation-v1` 履约凭证、签发者名单与撤销列表、CSV 交付复算、五级证据等级、信誉准入与可选本地链上承诺。公开入口覆盖凭证签发、核验、策略加载、链上证据核验与信誉聚合，不依赖数据库、Web 服务或 Cloudflare。

已实现能力：

- CSV 交付的输出格式、端到端转换、质量与履约复算。
- 凭证真实性、交付质量与履约成功分开记录。
- 信誉事件去重、冲突识别与分主体命名空间计数。
- 本地 Hardhat 链上承诺写入与独立回读。
- 独立消费者通过 tarball 安装 SDK 并完成核验。

未解决边界：

- 签发者名单与撤销列表为无签名 JSON，来源与版本只由文件字段自述。
- 记录账户为单一实验密钥，合约不校验签发者身份。
- 只有一种任务验证器，未验证跨任务共享信任核心。
- 证据报告见 [最小实验报告](report.md)。

## V0.2 — 两种任务共享信任核心

基线提交：`f1e3c4ebfcecbcba82b962ccc31c7d119dad00a9`
SDK：`@crewtrace/trust-sdk 0.2.0-preview.1`
CI：`45561483032`

V0.2 在不重写信任核心的前提下增加代码交付与固定测试集合验证，形成编译期内置的通用验证器注册表：`csv-ledger@csv-ledger-v1` 与 `code-artifact-test@code-artifact-test-v1`。验证器按标识与规则版本精确解析，未知标识与版本不会回退。

已实现能力：

- 代码任务凭证、固定测试集合、测试报告与执行器环境标识。
- 输出格式、端到端履约、质量与代码测试结果分开核验。
- 跨任务信誉隔离，CSV 与代码任务分别分桶。
- 跨进程 Agent 凭证交换，消费者只读取公开凭证、名单与证据。
- 80 项测试与独立消费者 21 项检查通过。

未解决边界：

- 代码验证过程会直接执行凭证携带的样本，不可信凭证可能触发执行。
- 名单与撤销列表仍为无签名 JSON。
- 只有一个实验签发主体，未验证多签发主体之间的信任关系。

## V0.3 — 多主体信任与链上独立核验

验收记录：`9bb00f867a30d6390fad4e1e6d5401102e9cc07d`

冻结归档 HEAD：`8b5fe58e80450561829e62572aef128465492aa0`，归档 CI [45568182070](https://github.com/NextVariable/crewtrace-v2/actions/runs/45568182070)。
验证提交：`ce893702a32a185f2a4684efabfce6acbb40dba0`
SDK：`@crewtrace/trust-sdk 0.3.0-preview.1`
Final CI：`45566951198`

V0.3 停止扩展验证器数量，重点验证多签发主体信任配置、独立代码执行授权与本地链上独立回读。

已实现能力：

- `ct-trust-config-v1` 签名信任配置：版本、有效期、信任根、名单、撤销列表、摘要与签名。
- 配置加载拒绝篡改、过期、未生效、版本回滚、根公钥不匹配与撤销列表完整性问题。
- `ct-code-execution-grant-v1` 独立代码执行授权，审批身份与签发身份分离。
- 不可信凭证不触发代码验证器，代码执行失败关闭。
- 内置验证器注册表与解析结果运行时冻结。
- 多签发主体进程实验：同时信任 A 与 B、只信任 A、拒绝未授权 C、密钥轮换、凭证撤销与密钥撤销。
- 本地链上多主体承诺、签发者与记录者区分、未授权签发者与记录者拒绝、撤销后历史承诺保留、签名凭证与链上承诺差异检测。
- 信誉按签发来源与任务类型分桶，不合并为全局信用分。
- 118 项测试与独立消费者 22 项检查通过。

未解决边界：

- 信任根仍由单一受控操作者持有，没有透明日志、多签、门限签名或硬件密钥。
- 名单与撤销分发没有独立监督或公开撤销广播。
- 链上记录账户为单一受控账户。
- 本地 Hardhat 结果不代表公共链跨机器可用性。
- Node `vm` 只适用于受控合成样本，不是第三方任意代码安全沙箱。
- 去重没有跨进程全局唯一约束。
- 没有真实外部开发者采用。

完整报告见 [V0.3 多主体信任与链上核验报告](v0.3-multi-issuer-report.md)，测试证据见 [V0.3 测试与消费者验收证据](v0.3-test-evidence.md)，冻结状态见 [V0.3 阶段验收与开发冻结](V0.3-FREEZE.md)。
