# 多行文字流试版

首页由单行大字改为局部密集的小字文字场。桌面 11 行、手机 7 行，集中经过圆环中部，各行以略有差异的速度从右向左移动，文字维持正常阅读顺序。中心更清晰，外围和上下边缘淡出，环边保留折射、色散与柔化。

内容使用 CrewTrace 品牌短句与协作词语，属于装饰，不表示真实任务执行日志。沿用已有 Canvas 纹理和 WebGL 着色器，没有增加依赖。圆环几何、闪光对比、加入入口及工作区未修改。

后续按用户确认，将短句与词语替换为 14 条完整英文句子，每行组合不同句子循环显示，实际流速提高 30%。扩展纹理宽度以容纳句子，同时补偿纹理坐标，保持字号与行数。构建及桌面、手机、暂停和减少动态效果检查再次通过。

验证：类型检查和生产构建通过，存在既有包体积警告；实际浏览器检查桌面与手机截图，暂停、恢复和减少动态效果通过，未出现页面 JavaScript 异常。自动浏览器检查不代表真实手机性能验收。
