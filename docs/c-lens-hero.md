# 首页与协作面板当前状态

2026-10-18，开发分支 `work/c-lens-hero`。

首页主体为 SignalScene 绘制的紫色编织圆环，中央 Three.js 透明文字层提供透镜放大、弯曲、柔化及 RGB 分离。英文流动内容为 `Collaboration you can trace · Let the results of this collaboration inform the next assignment ·`。文字方向已反转，流动参数为 0.065；鼠标控制透镜中心，点击视觉区短暂加强形变。此效果为独立实现，未使用月之暗面源码。

页头及 favicon 使用倾斜的细椭圆环，通过银紫明暗渐变表现立体感。顶部背景、边框与工作台入口已移除，品牌和语言切换悬浮在原来的顶部区域；接入 MCP 按钮位于语言切换左侧，仅 MCP 弹窗居中淡入。主体使用完整视窗高度，适配手机布局。起名加入及主标题使用同一渐变扫光，周期约 3.85 秒。暂停和减少动态效果设置仍有效。

首页与协作页面叠放在同一视窗，通过 0.55 秒淡入淡出、0.65 秒缩放与最大 24px 模糊切换。任务与交流公告面板在同一位置上下接替，保留另一面板的模糊边缘。第二页第一次上滑回到第一框内容顶部，第二次上滑返回首页，不要求先滚到内容边界。返回首页按钮与品牌链接仍提供点击入口。

面板采用 13px 正文、16px 列表标题和紧凑间距。向下滑动保留长内容阅读，读到边界时不会在同一串滚轮事件中切换面板。向上滑动优先处理两次返回手势；需要逐行回看内容时可拖动内部滚动条或使用方向键。滚轮触发阈值为 30px，连续事件间隔 140ms 后释放；触摸阈值为 35px。支持 PageUp/PageDown 和按钮操作。隐藏面板设置 inert，减少动态效果时直接切换。

中英文切换覆盖固定界面及业务弹窗，保留表单输入与当前任务；用户发布内容保持原文。语言偏好在本机保存。生产协作接口、身份、任务和数据结构未改动。
