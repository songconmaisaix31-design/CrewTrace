最新方向调整：Logo 圆环长轴沿左上至右下倾斜，页头与 favicon 一致。流动英文由右向左移动，保持字符的正常阅读顺序，句首先经过观察位置、句尾随后经过；起始纹理偏移归零，中央透镜折射保持。

首页主体为 SignalScene 绘制的紫色编织圆环，中央 Three.js 透明文字层提供透镜放大、弯曲、柔化及 RGB 分离。英文流动内容为 `Collaboration you can trace · Let the results of this collaboration inform the next assignment ·`。文字方向已反转，流动参数为 0.065；鼠标控制透镜中心，点击视觉区短暂加强形变。此效果为独立实现，未使用月之暗面源码。

页头及 favicon 使用倾斜的细椭圆环，通过银紫明暗渐变表现立体感。顶部背景、边框与工作台入口已移除，品牌和语言切换悬浮在原来的顶部区域；接入 MCP 按钮位于语言切换左侧，仅 MCP 弹窗居中淡入。主体使用完整视窗高度，适配手机布局。起名加入及主标题使用同一渐变扫光，周期约 3.85 秒。暂停和减少动态效果设置仍有效。

首页与协作页面固定覆盖整个视窗，通过 0.32 秒淡入淡出、0.42 秒缩放与最大 24px 模糊切换。圆环画布使用径向透明遮罩，避免光晕在画布边界截成矩形。Logo 使用三维旋转后的细圆环及银紫光泽。任务与交流公告面板在同一位置以 0.36 秒上下接替，保留另一面板的模糊边缘。第二页第一次上滑回到第一框内容顶部并产生轻微位移反馈，第二次上滑返回首页。返回首页按钮与品牌链接仍提供点击入口。

面板采用 14px 正文、17px 列表标题、12px 辅助信息和 22px 详情标题，手机详情标题为 20px。默认滚动直接翻页，不受长内容位置影响。点击「阅读内容」进入独立阅读，可原生上下滚动；点击「退出阅读」恢复翻页，切换面板或页面也退出阅读。滚轮触发阈值为 12px，通过事件间隔、方向反转和新手势加速度区别连续惯性与新手势；触摸阈值为 20px。支持 PageUp/PageDown 和按钮操作。隐藏面板设置 inert，减少动态效果时直接切换。
