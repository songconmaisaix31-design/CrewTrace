# 首页透镜动效

2026-10-18，开发分支 `work/c-lens-hero`，基于 `cbe3f22`。

公开协作首页以放大的紫色编织线条圆环为主体，复用 SignalScene 绘制；Three.js ShaderMaterial 在其中央叠加透明文字层，文字在中心收束、两侧拉伸，边缘使用多次采样柔化及 RGB 分离。纹理宽度按整串英文实测长度生成，减少循环尾部空白。流动参数为 0.065，鼠标延迟跟随控制透镜中心，点击视觉区短暂加强形变，滚动时画面收缩淡出。这是参考视频效果的独立实现，未使用月之暗面源码。

首页文案为「协作有迹可循」「以履历驱动的 Agent 协作网络」「让这次合作的成果，成为下次分工的依据。」「向下探索」。本次只调整展示，没有新增自动分工功能。

页头标志直接复用 SignalScene 的编织圆环，桌面显示 66px、手机 54px；favicon 使用同形 SVG，位于 `apps/web/public/crewtrace-mark.svg`。流动文字为 `Collaboration you can trace · Let the results of this collaboration inform the next assignment ·`，固定英文作为品牌视觉。文字方向反转，中央恢复明显的透镜放大和弯曲折射。圆环下方为放大的起名加入按钮与单行自适应标题；「协作有迹可循」及成果说明位于首屏左上方。按钮及主标题使用与英文流动周期相同的渐变扫光，暂停和减少动态效果设置同时控制。登录后按钮显示已有身份，继续打开身份管理。页头右侧仅保留语言切换。

页面分为圆环首页和协作舞台两个视觉画面，两屏叠放在同一视窗，通过淡入淡出、轻微缩放与模糊过渡切换。滚轮连续事件设置惯性保护，避免一次手势跳过任务面板。任务、交流公告两个面板在同一位置上下接替，保留另一面板的模糊边缘。任务与消息在当前面板内独立滚动；边界滚动切换面板，第二屏上滑不自动退出，点击「返回首页」或品牌返回。支持触摸滑动、PageUp/PageDown、切换按钮及方向提示，隐藏面板设置 inert 避免误点或键盘进入。减少动态效果时直接切换可见面板。打开关联任务时返回任务面板，保留真实任务和业务数据。弹窗独立于两屏渲染，首屏仍可打开身份与 MCP 窗口。

右上角中英文切换覆盖当前公开协作页面、任务详情、表单、弹窗、状态、错误说明和 MCP 接入资料。弹窗内也可切换语言，切换不重建业务组件，因此保留表单输入与当前任务。语言偏好保存在本机，日期及 document.lang 随语言变化。品牌名、用户发布的任务与交流内容、身份名称、标识符和协议字段保持原文。英文接入指令和 Skill 具有单独的下载文件。

首页提供暂停按钮，减少动态效果设置关闭持续动画，隐藏浏览器页面停止渲染，组件卸载释放纹理与渲染资源。手机限制像素比，WebGL2 不可用时显示静态品牌画面。

验证：类型检查与生产构建通过，现有 HTTP 测试此前 2/2 通过。真实本机 Chrome 检查桌面着色器、鼠标操作、暂停与恢复、进入协作锚点、390px 布局和减少动态效果，未发现页面或着色器错误。`browser-language.spec.ts` 本次 2/2 通过，覆盖按钮迁移、扫光参数随时间变化及暂停后保持、语言刷新持久化、双语表单输入保留、真实公开任务内容与选择保持、MCP 英文资料地址及手机布局。截图与临时检查脚本保存在忽略目录 `.local/`。本次没有进行生产数据写入或线上部署。

当前限制：Three.js 增加首页资源体积，构建产生大于 500 kB 的分块提示；尚未在真实手机上验证性能。后续可根据用户反馈调整文字速度、折射强度和光晕范围。

协作舞台验证：`browser-stage.spec.ts` 通过，使用真实滚轮事件检查淡入切页、连续滚轮保护、两面板最终位置和尺寸一致、上下切换、边缘预览、inert、内部滚动、390px 页面宽度和减少动态效果。向上滚动留在第二屏，点击返回入口回到首页。生产记录仅被读取，没有创建测试身份或协作数据。
