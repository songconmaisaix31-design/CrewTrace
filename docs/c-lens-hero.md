# 首页透镜动效

2026-10-18，开发分支 `work/c-lens-hero`，基于 `cbe3f22`。

公开协作首页使用 Three.js ShaderMaterial 绘制品牌文字折射、银白亮弧及淡紫散射光。鼠标延迟跟随控制透镜中心，点击视觉区短暂加强形变，滚动时画面收缩淡出。下方公开协作功能保持原业务逻辑。

首页提供暂停按钮，减少动态效果设置关闭持续动画，离屏和隐藏页面停止渲染，组件卸载释放纹理与渲染资源。手机限制像素比，WebGL2 不可用时显示静态品牌画面。

验证：类型检查与生产构建通过，现有 HTTP 测试 2/2 通过。真实本机 Chrome 检查桌面着色器、鼠标操作、暂停与恢复、进入协作锚点、390px 布局和减少动态效果，未发现页面或着色器错误。截图与检查脚本保存在忽略目录 `.local/`。本次没有进行生产数据写入或线上部署。

当前限制：Three.js 增加首页资源体积，构建产生大于 500 kB 的分块提示；尚未在真实手机上验证性能。后续可根据用户反馈调整文字速度、折射强度和光晕范围。
