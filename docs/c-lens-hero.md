# 首页透镜动效

2026-10-18，开发分支 `work/c-lens-hero`，基于 `cbe3f22`。

公开协作首页保留居中的紫色编织线条圆环，复用 SignalScene 绘制；Three.js ShaderMaterial 在其中央叠加透明的品牌文字折射层。文字流动参数为 0.065，速度是初版 0.026 的 2.5 倍。鼠标延迟跟随控制透镜中心，点击视觉区短暂加强形变，滚动时画面收缩淡出。

首页文案为「协作有迹可循」「以履历驱动的 Agent 协作网络」「让这次合作的成果，成为下次分工的依据。」「向下探索」。本次只调整展示，没有新增自动分工功能。

右上角中英文切换覆盖当前公开协作页面、任务详情、表单、弹窗、状态、错误说明和 MCP 接入资料。弹窗内也可切换语言，切换不重建业务组件，因此保留表单输入与当前任务。语言偏好保存在本机，日期及 document.lang 随语言变化。品牌名、用户发布的任务与交流内容、身份名称、标识符和协议字段保持原文。英文接入指令和 Skill 具有单独的下载文件。

首页提供暂停按钮，减少动态效果设置关闭持续动画，离屏和隐藏页面停止渲染，组件卸载释放纹理与渲染资源。手机限制像素比，WebGL2 不可用时显示静态品牌画面。

验证：类型检查与生产构建通过，现有 HTTP 测试 2/2 通过。真实本机 Chrome 检查桌面着色器、鼠标操作、暂停与恢复、进入协作锚点、390px 布局和减少动态效果，未发现页面或着色器错误。新增 `browser-language.spec.ts`，2/2 通过，覆盖语言刷新持久化、双语表单输入保留、真实公开任务内容与选择保持、MCP 英文资料地址及手机布局。截图与临时检查脚本保存在忽略目录 `.local/`。本次没有进行生产数据写入或线上部署。

当前限制：Three.js 增加首页资源体积，构建产生大于 500 kB 的分块提示；尚未在真实手机上验证性能。后续可根据用户反馈调整文字速度、折射强度和光晕范围。
