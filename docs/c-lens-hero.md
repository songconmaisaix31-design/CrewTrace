# 首页与协作面板当前状态

2026-10-18，开发分支 `work/c-lens-hero`。

首页主体为 SignalScene 绘制的紫色编织圆环，中央 Three.js 透明文字层提供透镜放大、弯曲、柔化及 RGB 分离。英文流动内容为 `Collaboration you can trace · Let the results of this collaboration inform the next assignment ·`。文字方向已反转，流动参数为 0.065；鼠标控制透镜中心，点击视觉区短暂加强形变。此效果为独立实现，未使用月之暗面源码。

页头及 favicon 使用单根细圆环。首屏左上角辅助文案已移除。接入 MCP 按钮位于动效区右上角，按钮内容不变，仅 MCP 弹窗居中淡入。起名加入及主标题使用同一渐变扫光，周期约 3.85 秒，比上一版快四倍。暂停和减少动态效果设置仍有效。

首页与协作页面叠放在同一视窗，通过淡入淡出、缩放和模糊切换。任务与交流公告面板在同一位置上下接替，保留另一面板的模糊边缘。第二框上滑回第一框，再上滑可回首页；直接在第一框顶部上滑需两次独立手势。返回首页按钮与品牌链接仍提供点击入口。

面板采用 13px 正文、16px 列表标题和紧凑间距。长内容保留完整阅读，框内滚动到边界时不会在同一串滚轮事件中切换面板，松开后再次滑动才切换。支持触摸、PageUp/PageDown 和按钮操作。隐藏面板设置 inert，减少动态效果时直接切换。

中英文切换覆盖固定界面及业务弹窗，保留表单输入与当前任务；用户发布内容保持原文。语言偏好在本机保存。生产协作接口、身份、任务和数据结构未改动。

验证：类型检查与生产构建通过；现有 HTTP 测试 2/2、Chrome 浏览器检查 3/3 通过，额外重新运行面板检查验证框内滚轮到边界不触发翻页。检查覆盖居中弹窗、双语输入保留、真实任务读取、两面板同位切换、滚轮返回首页、手机布局与减少动态效果。截图保存在忽略目录 `.local/`。未创建生产测试数据，未部署。
