# 中美 AI 与科技官网参考研究

研究时间：2026-10-17，北京时间。用途：为 co-vibe 的任务入口、执行过程、履历详情和深色紫色视觉提供设计依据。

## 证据范围

本轮读取了美国 Linear、Cursor、Anthropic 的官网，以及中国月之暗面和 MiniMax 官网，补读 Linear 与 Kimi 官方品牌规范。Kimi 属于月之暗面，同一公司不重复计数。

月之暗面首页成功取得浏览器 DOM，确认导航、输入框、空输入禁用的发送按钮，以及产品与 API 的独立入口。其余结论以官网可读内容和官方设计规范为依据。内置浏览器页面读取与截图多次超时，本机 Chrome 操作也被控制保护中断；未取得可接受的页面截图，未完成悬停、滚动动效、移动端或登录后完整流程实测。

因此本文是页面结构与官方设计资料研究，不能称为已完成视觉或交互实测。未根据文本推断实际空间尺寸、当前页面色值、动画时长或按钮手感。没有安装、调用 Firecrawl；本轮可用工具及本机命令中未找到其入口。

## 美国参考

### Linear：用具体工作解释产品

来源：https://linear.app/ 与 https://linear.app/brand 。

官网内容以工作对象、状态、活动和审查过程展示产品，提供具体任务情境。品牌规范强调标识周围的空间，给出灰白与深灰的单色使用方案；其官方描述的主品牌色为低饱和蓝，不应称为紫色品牌。

对 co-vibe 的建议：协作卡片展示真实任务、执行者和状态；证据与交接作为任务详情，而非首页铺满技术字段。黑灰承担结构，紫色承担主操作与选中提示。采用信息层级原则，不复制 Linear 的 Logo 或品牌资产。

### Cursor：展示执行过程与交付结果

来源：https://cursor.com/ 。

官网可读结构包含进行中与待审查的工作示例、当前动作，以及结果说明和后续入口。页面中存在明确标注的产品演示；本轮未验证演示控件的实际点击行为。

对 co-vibe 的建议：每个角色使用具体动作描述，例如正在整理数据或核对指标。成果与来源记录并列可查。官网演示的表现方式不能直接作为真实任务状态；co-vibe 的运行效果必须由后端实际事件驱动。

### Anthropic：区分公司叙事与产品使用

来源：https://www.anthropic.com/ 。

公司官网突出研究、使命和发布内容，产品、登录与开发者入口另有组织。这属于公司信息入口，与任务型工具的用户目标不同。

对 co-vibe 的建议：保留准确品牌说明，首页操作入口尽早出现；不照搬长篇公司介绍与研究资讯的内容顺序。当前没有逐屏截图，不评价其具体配色与动画。

## 中国参考

### 月之暗面：品牌与体验入口同时出现

来源：https://www.moonshot.cn/ 。

浏览器 DOM 显示：导航区分 Kimi、企业服务、API、研究和下载；首屏内容包含品牌说明、问题输入和体验入口；发送按钮在空输入时为禁用状态。下方内容按研究、功能和下载组织。未提交问题或登录。

对 co-vibe 的建议：让用户在首屏看到示例文件、交付说明和开始入口。无需借用自由聊天输入框，因为本次只允许固定工作流。条件不足时禁用操作，并在旁边说明原因。普通用户的查看入口与授权执行入口清楚区分。

### Kimi 官方设计规范：颜色分工与可见历史

来源：https://www.kimi.com/resources/kimi-brand 。

官方规范分别讨论品牌色、灰阶、排版和网格，并描述侧边栏历史、可视化进展以及界面细节。规范主品牌为蓝色；其界面介绍也包含暖白页面，并不支持“AI 科技界面必须是深色紫色”的结论。官方数据可视化说明强调准确与克制。

对 co-vibe 的建议：借用中性色组织层级、强调色引导焦点的原则，继续使用用户选择的紫色。历史运行应容易返回，切换轮次不丢上下文。模型履历与真实指标准确表达，不借用亲密度或升级动画来表现尚未证明的能力增长。长文本使用常规易读字体，交易哈希等技术值可采用等宽字体；中文字体仍需在原型中验证。

### MiniMax：按用户目标组织入口

来源：https://www.minimax.cn/ 。

官网内容把模型、产品和 API 分开组织，产品说明用实际用途引导体验；不同产品有各自入口。这些来自可读页面结构，菜单如何展开和转场未实测。

对 co-vibe 的建议：首页只突出当前可交付的数据分析任务。Agent 履历、交接与链上记录按需查看，开发者文档作为辅助入口。避免因多个底层能力而堆出同等醒目的按钮。

## 转为 co-vibe 设计建议

首屏保留品牌文案，突出示例文件、预期成果与主要操作。执行时呈现三个业务角色和当前动作，履历、候选比较及交接详情按需打开；报告完成后突出成果阅读与下载。

运行历史保留可见入口，切换轮次时明确当前所看的运行和时间。分工理由先给自然语言结论，再给角色记录、负载、快照与原始证据。公共访客先查看真实历史，授权用户才发起执行。

深色紫色是用户选择，不是样本站点共同使用的配色。沿用背景 #0C0A12、面板 #171320 与灰白正文；按钮 #7C3AED 配白字及浅紫焦点属于此前审查建议，等待实际设计采用与验证。主色不同时承担成功、失败及等待的全部语义。

没有得到可验证的官网动效录制，不抄写其动画参数。co-vibe 动效建议继续限制为操作反馈和真实状态变化，交接时短暂反馈；尊重减少动态效果设置，不以持续光点伪装实时通信。

## 后续验证

浏览器稳定后补充同一视口的首屏与关键展开状态截图，核对实际导航、按钮、焦点、滚动与动效。当前研究足以支持信息架构讨论，不能替代视觉方案选择或成品验收。
