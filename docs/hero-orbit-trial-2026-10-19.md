# 首页闭合文字轨道试版

当前状态：用户已否定两轮闭合轨道试版，首页恢复 `e4d26bb` 的横向穿环文字流。只在环外加入很轻的静态弧度，最大偏移为场景高度的 0.96%，不改变方向、速度、字号、亮度及环内透镜。与该原版逐行比较，`LensHero.tsx` 仅新增这一行弧度计算。类型检查、生产构建通过，实际页面已查看，浏览器错误日志为空；本次未重复运行自动化交互套件。以下内容保留为已结束的试验记录。

文字从横向直流改为倾斜闭合轨道：近侧向左穿过圆环中心，远侧向右回流。轨道角度驱动文字纹理移动，沿圆周采用整数次重复，避免轨道首尾出现位置接缝。中央透镜、鼠标形变、色散和亮弧保持；主圆环的几何、大小、光影和呼吸参数不变。

远侧文字缩小、退暗，并在主圆环区域进一步降低存在感。桌面显示两侧转弯与背景回路；手机保持圆环优先，轨道两侧受窄屏裁切，完整循环的可见程度弱于桌面。本轮没有增加粒子、小环或额外界面入口，没有改写文字内容、声音、协作数据或滚动规则。

闭合路径表达协作的持续流转与历史积累，是品牌装饰。它不代表真实任务事件、链上交易流向或去中心化网络拓扑。

桌面 1100×850、手机 390×844 已实际查看，桌面浏览器错误日志为空。截图保存在忽略目录 `.local/orbit-trial/`。此前版本由 Git 提交 `e4d26bb` 保留，可用于后续比较；未覆盖或删除原版历史。

## 用户纠正后的尺度与朝向

用户指出首版将文字轨道放反，而且轨道过小。修正版翻转投影面、倾斜方向和流动方向，文字保持正常字形，当前可见弧段改为向右推进。轨道横向直径约为视窗宽度的四倍，圆心移到画面下方之外；对向回程不再出现在首页上方。当前发光圆环作为巨型文字轨道上的单个节点，页面仅观察到文字在这个节点附近的穿入、折射和穿出，不能在一屏内看到完整文字椭圆。

字体高度按场景尺寸计算，避免轨道放大同时放大字形。主圆环保持不变。宽屏 1100×850 和默认窄屏已实际查看，浏览器错误日志为空，生产构建通过。修正版截图保存于 `.local/orbit-trial/giant-orbit-desktop.jpg` 与 `giant-orbit-corrected.jpg`。
