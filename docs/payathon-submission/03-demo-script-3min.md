# 三分钟演示脚本与录制方案

演示目标：用真实运行的三个独立 Agent 完成一次免费 CSV 服务，展示从下单、执行、交付、复算验收到信誉记录的完整链路，并如实说明支付宝正式支付尚未验证。

## 录制前准备

本机启动演示栈，不开启公网隧道：

```bash
cd CrewTrace-reputation-v2
npm run build
./deploy/local/start.sh
```

确认三个 Worker 在线、Runtime 与网关仅监听 127.0.0.1，然后使用浏览器打开 `http://127.0.0.1:8080`。准备一份非敏感 CSV 样例，包含重复行、缺失值与金额列，不含任何真实客户信息。关闭浏览器无关标签页，使用干净的浏览器配置，窗口 1440×900，页面缩放 100%。

录制前清空本地演示数据库中的历史订单或使用新 Agent 名称，避免画面出现历史数据。演示期间保持支付模式 `disabled`，不展示任何管理端页面。

## 脚本

| 时间 | 画面操作 | 旁白 |
| --- | --- | --- |
| 0:00-0:15 | 展示主页与产品标题 | CrewTrace 让 AI 服务按实际用量收款，并交付可复算、可追责的结果。今天演示一次真实的三 Agent 履约。 |
| 0:15-0:35 | 打开 Cloudflare Pages 展示站，滚动到工作流与 Agent 板块 | 这是已经上线的免费展示站。买方只需要一个 CSV 文件，系统会把任务拆给三个独立 Agent：结构巡检、数据清洗、证据报告。 |
| 0:35-0:50 | 回到演示页，注册买家 Agent | 我先注册一个买家身份。注册不需要支付，拿到凭证后就可以下单。 |
| 0:50-1:10 | 创建免费订单，展示服务名与 ¥0 价格 | 选择免费体验服务，价格为零，所以不进入支付流程，订单直接进入执行。付费服务的价格是 1 元，支付未开通时创建付费订单会被明确拒绝。 |
| 1:10-1:40 | 订单详情页，三个 Agent 依次接单执行 | 三个 Agent 按顺序执行：第一个做结构巡检，第二个做去重清洗，第三个生成证据报告。每一步都有独立任务状态，不是同一个进程假装成三个角色。 |
| 1:40-2:05 | 打开交付物，下载清洗结果与报告 | 交付物包含清洗后的 CSV 和证据报告。报告记录输入摘要、规则版本和复算结果，买方可以自己核对。 |
| 2:05-2:25 | 在订单页执行验收，展示结果 | 验收时系统会复算交付物，结果一致才记录通过。这里只对数据复核角色记录信誉事件，其他角色不写入信誉，避免虚高。 |
| 2:25-2:45 | 再次提交相同订单，展示幂等；刷新页面 | 重复提交同一个幂等键不会生成第二笔订单。刷新页面后，订单与凭证仍然可以恢复。 |
| 2:45-3:00 | 展示支付状态说明页与 402 流程示意 | 支付宝按量付费按 402 协议对接：返回付款要求，付款后携带支付凭证验付。代码已经实现，但正式商户验证还没完成，所以今天不展示真实付款，也不会用模拟支付冒充。 |

## 录制方案

使用系统自带录屏或 OBS，1080p、30 帧，麦克风单独录制，录完对齐。先完整彩排一次，确认免费订单在 40 秒内完成；如果第一次执行较慢，把 1:10 至 1:40 的快进处理成 1.5 倍速并加字幕说明。

画面只保留浏览器窗口与必要的终端输出，不展示管理端、环境变量、密钥文件或数据库。终端里不出现任何 Token。录制结束后停止演示栈：

```bash
./deploy/local/stop.sh --pg
```

成片控制在 2 分 50 秒到 3 分钟，字幕同时给出中英文关键句。上传到免费平台，不购买存储或转码服务。

## 录制检查

录制完成后逐项确认：没有真实客户数据，没有本机路径与密钥，没有公网隧道地址，没有把免费订单说成付费订单，没有出现“支付宝已接入”或“支付已验证”的表述，画面中的价格与代码一致，三个 Agent 的角色名称与执行顺序正确。

## 不能说的话

不要声称已经接入支付宝官方支付、已经完成真实交易、已经产生付费用户。演示中的免费服务与付费链路是两条不同的路径，旁白必须区分。付费服务的真实支付验证属于官方接入步骤，未完成前只展示代码与协议说明。
