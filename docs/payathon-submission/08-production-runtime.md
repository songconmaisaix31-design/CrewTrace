## 可选路径与限制

**A. Cloudflare Quick Tunnel。** 免费，不需要账号与域名，但地址每次启动变化，无 SLA，进程退出即不可用。只能用于临时验收，不满足评审期固定访问。

**B. Cloudflare Named Tunnel + 自有域名。** 免费方案支持命名隧道，但要求域名已托管在 Cloudflare。仓库与当前设备没有可用于生产的域名；用户约束为不购买域名。若报名账号持有人已经持有可托管域名，可以进一步验证，但目前没有该条件，不能视为可用方案。

**C. 免费 PaaS 托管。** 需要能运行 Node 进程与 PostgreSQL 的平台。常见免费额度通常要求绑定支付方式、存在休眠或冷启动，或者只提供 SQLite。仓库没有在这些平台完成部署与验证，不能在材料中声明可用。

**D. Cloudflare Workers 与 D1。** Workers 免费计划不能直接运行现有 Node 服务与 PostgreSQL，D1 是 SQLite，迁移需要重写数据访问与调度逻辑，属于新开发，不在本轮范围。Cloudflare Containers 需要付费计划，不满足 ¥0 约束。

**E. Pages 静态站。** 只能展示介绍页，不能提供 Runtime、MCP 与三个 Worker，不能替代服务。

## 达到「已验证持续在线」所需条件

至少需要固定域名与命名隧道，或以其他方式取得稳定的 HTTPS 入口；Runtime、网关、三个 Worker 与 PostgreSQL 需要由进程管理器托管并在崩溃后自动拉起；Mac 需要保持不休眠、网络稳定、供电持续；需要连续多日定时健康检查并保存结果，覆盖重启与断网恢复。评审期前还需完成一次从冷启动到完整付费链路的复验。

在上述条件满足并完成连续验证前，生产运行状态保持「尚未验证」，不以临时隧道或 Pages 展示站宣称作品已正式部署。
