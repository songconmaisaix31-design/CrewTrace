# 08 · gstack

## 实际能力及未执行部分

来源 `garrytan/gstack`，固定版本 `67783c18857ebbcf5257dcc4a237435311869051`。它是工程、产品、浏览器和发布的编排框架；相关 Skill 是 `design-review/SKILL.md`。已检查 README 的安装依赖、审查阶段、截图原则、界面分类、交互检查及后续修复流程。

完整运行需 Claude Code、Bun、Aside 或其自带浏览器等；初始化可能下载、构建并修改配置，流程还包含外部评审、遥测、修复与提交。既有安全审查将完整执行列为高风险。本轮不执行 setup、不启动它的浏览器、不调用外部模型、不运行修复循环。本报告仅参考已检查的文字方法，**不属于完整 gstack 运行结果**。

## 使用的方法

采用其 Phase 1–6 中的首屏观察、按界面用途分类、逐页截图和流程一致性检查。本报告的视觉判断只依赖渲染截图和浏览器操作，不用源代码推断画面。首页属于 Experience 与 Persuade 混合，公开协作属于 Operate，详情正文属于 Read。没有采用其“所有字体必须大于 16px”等绝对规则作为 WCAG 结论，也没有虚构自动 AI 风格分数或跨模型一致性分数。

## 首屏观察

看[桌面首页](evidence/home-desktop.png)，视觉首先被圆环与穿过它的文字吸引，然后看到加入入口。它传达了实验性、网络与科技主题。主题有辨识度；“看完后我可以在这里完成什么”仍需通过较小的功能文字和进入工作区来理解。这是设计师观察，不是用户眼动实验。

| 编号 / 程度 | 具体证据 | 观察、原因与影响 | 建议 |
|---|---|---|---|
| G1 / P2 | [手机首页](evidence/home-390.png) | 大号流动英文在某一帧只呈现局部字母，无法承担完整产品说明；静态截图不能证明整段动画不可读，但能确认它不适合作为唯一解释载体 | 保留视觉装置，静态用途说明明确“为 Agent 发布、认领任务并留下协作记录”，入口附近即可，不增设大段介绍 |
| G2 / P2 | [桌面任务](evidence/tasks-desktop.png)、[横屏任务](evidence/tasks-844.png) | 内容少时展示区显得空，横屏时阅读高度又明显收缩。稳定切页空间有意义，但内部空间分配尚未适配不同内容与屏幕 | 稳定标签和方向按钮；矮屏压缩非内容占用，宽屏让内容自然排列、底部渐隐。无需随一条记录任意拉伸外框 |
| G3 / P2 | [任务详情](evidence/task-detail.png) | 标题和金额清楚，长说明之后才出现协作轨迹。对回访检查工作进度的人，正文和操作的阅读优先级不匹配 | 详情顶部加入轻量锚点及真实状态摘要，长说明作为可直接定位的内容，不截掉交付要求 |
| G4 / P2 | [筛选空结果](evidence/tasks-filter-cancelled.png) | 空态告知没有任务，但恢复路径主要依赖用户自行回到筛选器 | 在空态提供“清除筛选”，并说明是当前筛选无结果，不能暗示整个平台没有任务 |

## 值得保留与快速改善候选

首页没有套用三张功能卡片；品牌色贯穿弹窗和工作区；窄屏保持主要操作；居中弹窗和可关闭入口清楚。这些均可从截图核对。最小改善候选为详情补齐模拟金额说明、空态提供清除筛选、提高未选标签可读性。它们通常较局部，但本轮不承诺未经实施验证的“30 分钟完成”。

未输出 gstack 等级、自动检测数量或最终发布判定。登录后写入、真实触控板手感及硬件性能不在本次运行证据中。
