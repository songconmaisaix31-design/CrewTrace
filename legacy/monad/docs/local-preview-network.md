# 本地预览的代理配置

2026-10-19 核对：本机 macOS HTTP/HTTPS 代理为 127.0.0.1:12450。直接连接协作后端失败，通过现有代理可返回真实任务。此前重启 Vite 未带上代理环境，造成 /api/web 返回 502、页面显示尚未获取任务；原有记录仍在后端。

在本机当前代理配置保持不变时，从仓库根目录启动：

```sh
NODE_USE_ENV_PROXY=1 HTTPS_PROXY=http://127.0.0.1:12450 HTTP_PROXY=http://127.0.0.1:12450 NO_PROXY=localhost,127.0.0.1 npm run dev --workspace @co-vibe/web
```

本次 Node 为 v26.10.0。代理变量须在启动进程前设置；不要只放进 Vite 随后读取的配置并假定 Node 已使用。更换网络或代理端口后先核对系统实际设置，不修改线上部署配置，也不把本机代理写死到产品代码。
