# 支付宝 PAYATHON 开发范围

用户已授权在独立分支开发完整支付宝参赛版本。分支 feat/alipay-payathon，基线 dcb9ae7。
使用当前 React / TypeScript / PostgreSQL / MCP。单 Agent 执行，按领域、接口、界面、验收分别提交。

产品：专业 Agent 服务按次交易，服务发现、固定报价、用户确认、支付核验、交付、退回重交、验收、信誉。
主赛道 Machine Pay。官方规范来源与上线门槛见 docs/PAYATHON.md。
历史协议与原版完整保存在 legacy/monad；不转换原有模拟悬赏为人民币债务，不访问旧生产数据库。

验收：运行真实本地 PostgreSQL 引擎、HTTP 和官方 MCP 客户端完成免费真实服务及双身份交付；编译前后端；浏览器验证表单、响应式与权限。不使用模拟支付宝成功结果。
支付宝真实收费验收必须使用官方服务登记与密钥。无凭证时明确记录未完成，禁止宣称参赛上线完成。
