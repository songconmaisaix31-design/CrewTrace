# 07 · Design Skills

## 来源、方法与安全边界

来源为 `ihlamury/design-skills`，固定版本 `126714ec5df13a2c97ce1b3975e5a51d2592d967`。这是按品牌整理的 Skill 集合，并非单一评测器。已阅读 README、`linear/SKILL.md` 和 `awwwards/SKILL.md`；本次实际应用 `linear-ui-skills` 的操作状态、阅读层级和一致性检查。安全报告允许读取这些低执行风险的文本，不需要运行脚本或安装依赖。没有把全部品牌 Skill 都调用一遍。

Linear 的工作管理场景适用于 CrewTrace 的任务区；其具体配色、字号并非 CrewTrace 的品牌规范。Awwwards 预设主要服务展示型设计，其中竟有输入框高度 `0px` 的强制值，不能作为产品表单规范。本轮不应用它的尺寸要求。安全可读不代表设计建议正确，也不代表得到相应公司的官方认可。

## 判断与适用范围

现有紫色品牌、圆环和柔和边界无需为了匹配品牌模板而替换。任务状态文字、列表摘要和统一弹窗已经形成基础组件语言。最值得借鉴的是工作区的明确操作层级，不是把 CrewTrace 变成 Linear。没有运行评分器；以上属于文本 Skill 方法实际应用，视觉依据来自本轮真实页面。
